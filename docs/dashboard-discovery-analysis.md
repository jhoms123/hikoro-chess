# Player dashboard, room discovery and replay analysis

October 8, 2026. Updates preserve the credited artwork, original boards, account privacy and English/Cuban Spanish support.

The Player Hall overview brings together the current browser tab’s online seat, private cloud saves, device tables, account-scoped invitation bookmarks, six lesson milestones, recent opponents from the latest 50 account journals, and saved replays. Account saves use the existing signed-in Supabase client and owner filters. Saved invitations remain local to this device and account; foreign origins are rejected. Seat tokens never appear in the UI. Public room cards reveal only existing public lobby information.

Waiting rooms show game, host, occupied seats, board size where relevant, and clock. Game/time filters refresh against each lobby update. Disconnected join buttons are disabled. Finished and full rooms are not presented as joinable; the server remains authoritative if a room fills while joining.

The replay analysis worker uses the same game engines as server validation. It explains observed captures, immediate captures and wins available to the player to move, available alternatives before the recorded action, and bonus-turn/jump continuation. Shavari cover preserves captured-piece counts; Go shielding is not a capture; garden capture generation respects invulnerable Suns and Chysalith. Analysis does not change journals, comments, board state or scores. It is a one-turn explanation, not a deep engine evaluation or an assertion that an alternative is strategically best. Garden drops and Hikoro hand drops are sampled for alternatives; immediate board capture opportunities are checked. Analysis runs off the main UI thread and superseded requests are terminated.

Replay notation now follows each board’s coordinates, including 13-line Go’s omitted I file. UI refinements include a calmer app bar, consistent form/touch controls, dashboard cards, collapsible secondary records, readable empty states and a board-first desktop replay with the analysis below the board on phones. Material button decoration excludes app-bar, account and discovery controls so their spacing remains consistent.

Validation: 145 tests pass with --test-concurrency=2. An earlier unrestricted run hit one connection timeout under concurrent CPU load; the same integration passed on rerun. The added tests cover all six rule-engine analysis adapters, legal replay alternatives, state preservation, mandatory Go continuation, Shavari covering, coordinate labels, room filtering/disconnection, account-scoped invitations, unsafe player text and bilingual restoration. A focused rerun covers the final minor UI/notation changes. Hosted desktop and phone review follows before production merge.
