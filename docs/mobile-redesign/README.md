## Review

- No fixed bottom tray hides board cells.
- Original game controls are relocated rather than duplicated.
- Game-dependent actions remain in reach; 13×13 Go offers a larger initial view.
- Garden inventory is near its board, with only the active hand shown by default.
- All graphics/credit sources are unchanged.
- [Phone validation](validation.json) records 18 game/viewport checks; engine/socket validation is 57 passing tests.
- This branch is a preview for review, not a merged deployment.
