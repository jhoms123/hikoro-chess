# Shavari Go royal piece emblems

All nine game-piece emblems use SVG artwork from [Game-icons.net](https://game-icons.net/), released under the [Creative Commons Attribution 3.0 Unported license](https://creativecommons.org/licenses/by/3.0/).

- [Castle](https://game-icons.net/1x1/delapouite/castle.html) by Delapouite — Crownhold
- [Crown](https://game-icons.net/1x1/lorc/crown.html) by Lorc — High Marshal
- [Crenulated Shield](https://game-icons.net/1x1/lorc/crenulated-shield.html) by Lorc — Royal Guard
- [Knight Banner](https://game-icons.net/1x1/delapouite/knight-banner.html) by Delapouite — Standard-Bearer
- [Crossbow](https://game-icons.net/1x1/carl-olsen/crossbow.html) by Carl-Olsen — Crossbowman
- [War Pick](https://game-icons.net/1x1/delapouite/war-pick.html) by Delapouite — Sapper
- [Cavalry](https://game-icons.net/1x1/delapouite/cavalry.html) by Delapouite — Cavalier
- [Watchtower](https://game-icons.net/1x1/delapouite/watchtower.html) by Delapouite — Sentry
- [Pikeman](https://game-icons.net/1x1/delapouite/pikeman.html) by Delapouite — Squire

For each icon, the original solid background shape was removed and the foreground silhouette kept as a single-color SVG so the board renderer can tint it for each realm. The silhouettes remain the authors' original path geometry. The dark-SVG files are color variants for the ivory side; the game UI uses the matching shared silhouette when drawing both sides.

The optional “Shavari Chess emblems” style in Shavari Go reuses four existing Shavari chess icons: Lotus for the Crownhold, Elephant Head for the High Marshal, Camel for the Cavalier, and Gold Scarab for the Squire. Their original files, artist names, and CC BY 3.0 credit are recorded in `../shavari/CREDITS.md`.
