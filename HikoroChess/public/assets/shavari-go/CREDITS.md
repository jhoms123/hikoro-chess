# Shavari Go royal piece emblems

All six SVG source icons are from the [Game-icons.net source repository](https://github.com/game-icons/icons), licensed under [Creative Commons Attribution 3.0 Unported (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/).

- [Castle](https://game-icons.net/1x1/delapouite/castle.html) by Delapouite — Crownhold
- [Crown](https://game-icons.net/1x1/lorc/crown.html) by Lorc — High Marshal
- [Round Shield](https://game-icons.net/1x1/willdabeast/round-shield.html) by Willdabeast — Royal Guard
- [Tower Flag](https://game-icons.net/1x1/delapouite/tower-flag.html) by Delapouite — Standard-Bearer
- [Crossbow](https://game-icons.net/1x1/carl-olsen/crossbow.html) by Carl-Olsen — Crossbowman
- [Spears](https://game-icons.net/1x1/lorc/spears.html) by Lorc — Squire

The solid background was removed, and foreground colors were tuned for contrast on the dark and light game tokens. The original path geometry was retained. These SVGs are delivered locally so the game does not rely on an image host.

Each `*-dark.svg` file is a color-variant copy of its matching credited source icon, recolored for the ivory player’s token.
