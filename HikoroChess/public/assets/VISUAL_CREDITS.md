## Hikoro and Academy sprites

Hikoro and Academy continue to use the repository's existing original game sprites. The visual refresh deliberately displays small legacy sprites near their natural scale inside larger CSS-built medallions and lesson-book compositions instead of enlarging them into blurry promotional artwork.

## Sho Dan Sho

Sho Dan Sho retains its existing flower artwork and board. The collection card uses a CSS botanical composition and credited Kenney ornament rather than loading a full-size flower sprite into the lobby. The game page now preloads only the player colors required by the current match.

## CSS-built decoration

Wave lines, board grids, shields, medallions, strategy-hall geometry, card gradients, and similar decorative shapes in `visual-refresh.css` are CSS interface elements, not generated images.
